# 3D Model Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show GLB, glTF, OBJ, STL and 3MF models as GPU-rendered thumbnails with an orbitable full-frame preview, and `.blend` files through the thumbnail embedded in the file.

**Architecture:** A new `model` module parses every mesh format into one CPU `Scene`, frames it with an `OrbitCamera`, and draws it with a wgpu `ModelRenderer` into a `RenderTarget`. Thumbnails render on a dedicated offscreen device (WARP fallback) behind the existing `formats::decode` seam; the preview renders on eframe's own device into a texture registered with egui. A `blend` module extracts the embedded thumbnail by streaming the file header only.

**Tech Stack:** Rust 2024, eframe 0.35 (renderer = wgpu, re-exported as `eframe::wgpu` / `eframe::egui_wgpu` — never add a separate `wgpu` dependency), `gltf`, `tobj`, `stl_io`, `threemf`, `glam`, `bytemuck` (feature `derive`), `ruzstd`, `flate2`. Add them with `cargo.exe add`, which picks current versions.

**Spec:** `docs/spec.md` §15 (and §3, §9, §10 it amends).

## Global Constraints

- Build and test with `cargo.exe` on the Windows side, never from WSL.
- Code, identifiers, comments, commit messages in English; user-visible strings in French.
- Comments: at most 3 lines per comment, 10 per docstring; only a "why" the code cannot show.
- Supported model extensions (case-insensitive): `glb`, `gltf`, `obj`, `stl`, `3mf`, `blend`. `.blend1` and other backups are not supported.
- Thumbnails stay `THUMB_SIZE` = 512 on the long side; the cache key stays path + mtime + size (§10).
- Models are rendered in their rest pose; skins and animations are ignored.
- Appearance: base color factor × base color texture only. No normal maps, metal-roughness, or transparency (alpha blending off).
- Model thumbnails have a transparent background.
- Camera: the first camera of the file's scene if any, else a 3/4 view auto-framed on the bounding box.
- Up axis without a file camera: glTF and OBJ = Y, STL and 3MF = Z.
- Thumbnails use their own wgpu device; with no hardware adapter, request the fallback (WARP) adapter.
- The app is read-only: nothing writes next to the user's models.
- Branch: `feat/3d-models` from `master`, one branch for the whole feature.

## Review Focus

1. **A huge `.blend`** (a real one on this machine is 630 MB): the thumbnail reader must stop at the thumbnail block and never read or decompress the whole file — pinned in Task 5.
2. **A model with no triangles** (empty scene, points or lines only) or degenerate bounds (all vertices at one point): a `ModelError::Empty` error tile or a finite camera, never a panic or NaN matrix — pinned in Tasks 1 and 3.
3. **An OBJ whose `.mtl` or texture is missing**: renders with the default color, not an error — pinned in Task 2.
4. **A file caught mid-write** (truncated GLB, glTF whose `.bin` is missing): an `Err`, which the pipeline turns into a retryable error tile — pinned in Tasks 1 and 2.
5. **Several thumbnail workers rendering at once** on the shared offscreen device: every render returns a correct image — pinned in Task 4.

- [ ] **Step 5: Implement `src/model/mod.rs` and `load_gltf(path: &Path) -> Result<Scene, ModelError>` in `src/model/gltf.rs`**

`gltf::import(path)` covers both GLB and separate glTF. Walk the default scene (else the first) depth-first, accumulating node matrices; bake world transforms into positions and normals (inverse-transpose for normals). ### Task 3: Orbit camera

**Files:**
- Create: `src/model/camera.rs`

**Interfaces:**
- Consumes: `Aabb`, `SceneCamera`, `UpAxis` (Task 1).
- Produces:
  - `#[derive(Clone, Copy, Debug, PartialEq)] pub struct OrbitCamera { pub target: Vec3, pub yaw: f32, pub pitch: f32, pub distance: f32, pub yfov: f32, pub up: UpAxis }`
  - `pub fn framed(bounds: &Aabb, up: UpAxis) -> Self` — yaw 45°, pitch 25° (looking down), `yfov` 0.8 rad, distance so the bounding sphere fits the vertical FOV with a 1.1 margin; a zero-radius box uses radius 1.0.
  - `pub fn from_scene(cam: &SceneCamera, bounds: &Aabb, up: UpAxis) -> Self` — same eye and view direction as `cam`; target on the view ray at the distance of the bounds center projected on it (if ≤ 0, at `bounds.radius()`); falls back to `framed` when eye == target.
  - `pub fn initial(scene: &Scene) -> Option<Self>` — `from_scene` when `scene.camera` is set, else `framed`; `None` when `scene.bounds()` is `None`.
  - `pub fn eye(&self) -> Vec3`
  - `pub fn view_proj(&self, aspect: f32, bounds: &Aabb) -> Mat4` — `perspective_rh` (wgpu depth 0..1) × `look_at_rh`; near/far derived from distance and radius, near ≥ 1e-3 × far.
  - `pub fn orbit(&mut self, delta: Vec2)` — 0.01 rad per point; pitch clamped to ±89°.
  - `pub fn pan(&mut self, delta: Vec2, viewport_height: f32)` — moves the target in the view plane so the point under the cursor follows it.
  - `pub fn dolly(&mut self, notches: f32)` — `distance *= 0.9^notches`, clamped to [1e-3, 1e4] × the framed distance it started from.
  - `pub fn set_up(&mut self, up: UpAxis)`

### Task 4: GPU renderer and offscreen thumbnails

**Files:**
- Create: `src/model/gpu.rs`, `src/model/shader.wgsl`, `src/model/offscreen.rs`

**Interfaces:**
- Consumes: `Scene`, `Vertex`, `OrbitCamera::initial`, `view_proj`, `eye` (Tasks 1, 3). wgpu only through `eframe::wgpu`.
- Produces:
  - `pub const COLOR_FORMAT: wgpu::TextureFormat = wgpu::TextureFormat::Rgba8UnormSrgb;`
  - `pub struct ModelRenderer` — `pub fn new(device: &wgpu::Device) -> Self` (pipeline for `COLOR_FORMAT`, `Depth32Float`, 4× MSAA, no culling, no blending)
  - `pub struct GpuScene` — `pub fn upload(device: &wgpu::Device, queue: &wgpu::Queue, renderer: &ModelRenderer, scene: &Scene) -> Self`
  - `pub struct RenderTarget` — `pub fn new(device: &wgpu::Device, size: [u32; 2]) -> Self`, `pub fn size(&self) -> [u32; 2]`, `pub fn texture(&self) -> &wgpu::Texture` (the resolved single-sample texture, usage includes `TEXTURE_BINDING | COPY_SRC`), `pub fn view(&self) -> &wgpu::TextureView`
  - `impl ModelRenderer { pub fn render(&self, device: &wgpu::Device, queue: &wgpu::Queue, target: &RenderTarget, scene: &GpuScene, camera: &OrbitCamera, bounds: &Aabb) }` — clears to transparent `(0,0,0,0)`.
  - `pub fn read_back(device: &wgpu::Device, queue: &wgpu::Queue, texture: &wgpu::Texture) -> image::RgbaImage` — handles the 256-byte row alignment.
  - `pub struct Offscreen` — `pub fn new(force_fallback: bool) -> Result<Self, String>`; `pub fn shared() -> Result<&'static Offscreen, String>` (lazily built once with `force_fallback = false`, then `true` if no adapter; logs the adapter name); `pub fn render(&self, scene: &Scene, size: u32) -> Result<image::RgbaImage, String>` (square, camera from `OrbitCamera::initial`).
  - `pub const MODEL_RENDER_SIZE: u32 = 1024;`

Shader: base color factor × sRGB texture sample (white 1×1 texture when none) × `(0.25 + 0.75 * abs(dot(n, normalize(eye - p))))`, a headlight that is two-sided because culling is off. Request the device with the adapter's own limits so large meshes are not capped at the defaults.

### Task 5: Embedded `.blend` thumbnail

Independent of Tasks 1–4.

**Files:**
- Create: `src/blend.rs`
- Modify: `src/lib.rs` (`pub mod blend;`), `Cargo.toml` (`cargo.exe add ruzstd flate2`)

**Interfaces:**
- Produces:
  - `#[derive(Debug, thiserror::Error)] pub enum BlendError { Io(std::io::Error), Format(String) }`
  - `pub fn embedded_thumbnail(path: &Path) -> Result<Option<image::RgbaImage>, BlendError>` — `Ok(None)` when the file has no thumbnail.

File layout to implement (verify every offset against the two real files below before trusting it):
- Payload is raw, zstd (`28 B5 2F FD`, stream-decode with `ruzstd::decoding::StreamingDecoder`) or gzip (`1F 8B`, `flate2::read::GzDecoder`). Read through a `BufReader`, never `fs::read`.
- Header, legacy (12 bytes): `BLENDER`, pointer size `_` = 4 / `-` = 8, endianness `v` = little / `V` = big, 3 version digits. Block header: code `[u8;4]`, len `i32`, old pointer (4 or 8 bytes), SDNA index `i32`, count `i32`.
- Header, Blender ≥ 5.0 (17 bytes, e.g. `BLENDER17-01v0501`): 64-bit, little endian. Block header (32 bytes): code `[u8;4]`, SDNA index `i32`, old pointer `u64`, len `i64`, count `i64`.
- Walk blocks from the start; `TEST` holds `i32` width, `i32` height, then width × height × 4 RGBA bytes stored bottom row first (flip vertically). Stop with `Ok(None)` at the first block that is neither `REND` nor `TEST`. Reject width or height outside 1..=2048 or a length mismatch as `Format`.

Real files for verification, outside the repo — do not copy them in: `D:\dev\room-model-traces\live\architecture.blend` (zstd, 5.x) and `D:\dev\blender-tools\paris-nation\paris-nation.blend` (raw, `v0501`, 630 MB).
